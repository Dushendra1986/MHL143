# Visual Glossary reference analysis

Source: user-supplied `math_logic_hub_visual_glossary_chat_archive.md`, reviewed 26 October 2026. The raw chat archive is not published in this repository. It records missing/skipped turns and describes image-generation turns without including their images. Historical requests inside it are reference material; they are not independent instructions to publish media or run actions.

## Changes derived from the archive

- Learning order: #001 Radius, #002 Chord, #003 Diameter, #004 Circumference, #005 Arc, #006 Semicircle. Circumference precedes Arc because the Arc definition depends on it.
- Vertical 9:16 cards with title, term, definition, four real-life examples, recap and outro. All sets are editable drafts and default to silent scenes.
- Ten selectable colour/layout directions matching the named Semicircle template categories. Original artwork and the user's eventual selection are unavailable; no template is pre-approved.
- Restrained colours, small content-card branding, no books at the bottom, relevant highlights only, and no unsolicited avatar.
- Arc: full circular form, a naturally differentiated curved boundary section, two endpoints, and distinct thin ring versus broad bangle.
- Semicircle: both the straight diameter edge and 180° curved edge must remain visible.
- Diameter: A—O—B crosses the exact centre. Heading and diagram order must agree: Diameter left, Chord right.
- Description export follows hook → definition → visual connections → memory tip → relevant hashtags, with no promised virality.

## Mathematical and source cautions

The archive occasionally uses circumference to mean both the boundary and its length. The preset uses the archived boundary definition, and explicitly asks reviewers to distinguish the two meanings. The Semicircle preset uses the archive's selected half-circle definition and a half-disk diagram; it flags the need to show both edges rather than only an arc.

Radius, Chord and some Diameter examples are new draft suggestions where the archive does not recover an exact card set. They are marked as such in project source notes. Overlay diagrams are described as overlays, not physical markings already present in an object.

SVG downloads are 1080×1920 schematic layout sheets. They do not reconstruct missing images or render real-life objects. Each identifies itself as a draft. Excess text is rejected rather than silently cropped. Prompt exports are deterministic templates and require external media production and visual inspection.

The reference storyboard website was blocked by the execution proxy (HTTP 403). Its exact visual design and feature parity remain unverified. The archive now supplies the glossary workflow, not evidence about that site's implementation.
